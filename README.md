# 🏡 DreamSpace – My 3D Dream House

**An Interactive 3D Dream House Experience Using HTML, CSS, JavaScript, and Three.js**

## 📌 Project Overview

DreamSpace – My Dream House is an interactive 3D house visualization project developed using HTML, CSS, JavaScript, and Three.js. It allows users to explore a virtual dream house, view different rooms, and customize the colors of walls and furniture.

The project features five different viewing areas: Outside View, Living Room, Kitchen, Bedroom, and Bathroom. Users can rotate the 3D environment, zoom in and out, and navigate between rooms using interactive controls.

It also provides customization options that allow users to change furniture colors, adjust the house's wall color, and switch between daytime and nighttime environments.

The main purpose of this project is to demonstrate web development skills, interactive 3D visualization, and user interface design.

## 🎯 Project Objectives

- To develop an interactive 3D dream house using web technologies.
- To create a virtual environment where users can explore different rooms.
- To implement customizable wall and furniture colors.
- To provide interactive camera controls for rotating, zooming, and viewing the house.
- To apply HTML, CSS, and JavaScript in developing an interactive web application.
- To demonstrate the use of Three.js for creating and displaying 3D objects.

## ✨ Features

- **Interactive 3D House** – Displays a virtual house with detailed furniture and room arrangements.
- **Outside View** – Allows users to view the entire house and its garden.
- **Living Room** – Explore the living room, including the sofa, coffee table, TV, and TV stand.
- **Kitchen** – Explore the kitchen with cabinets, counter, refrigerator, and dining table.
- **Bedroom** – View the bed, mattress, pillows, and wardrobe.
- **Bathroom** – Explore the bathtub, sink, mirror, and toilet.
- **Color Customization** – Change the colors of walls and individual furniture items.
- **Day and Night Mode** – Switch between daytime and nighttime environments.
- **3D Camera Rotation** – Rotate the house view using the Rotate button.
- **Zoom Controls** – Scroll to zoom in and out.
- **Room Navigation** – Select different rooms to automatically move the camera to the selected area.
- **Reset Colors** – Restore the original colors of the house and furniture.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
