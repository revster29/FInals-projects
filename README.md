# Project Description

This repository contains two creative programming projects: **Mini Maze Challenge** and **3D Dream House**.

**Mini Maze Challenge** is a Java-based maze game developed using Java Swing. It challenges players to navigate through different maze levels, avoid walls, find the exit, and complete each level within the given time limit. The game features an animated player sprite, movement controls, sound effects, a timer, and multiple difficulty levels to provide an enjoyable gaming experience.

**3D Dream House** is a 3D visualization project that showcases a dream house through three-dimensional design. It demonstrates creativity, spatial design, and the use of 3D modeling concepts to create a virtual house environment.

Both projects demonstrate programming skills, creativity, problem-solving, and the practical application of technology in developing interactive games and digital designs.
